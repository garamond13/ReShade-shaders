# TheElderScrollsVSkyrimGraphicalUpgrade

- Modern borderless window (flip mod, tearing).
- Optionally replace TAA with DLSS (DLAA only).
- Replaced ambient occlusion (SSAO) with XeGTAO.
- Replaced bloom.
- Fixed/improved some shaders.
- Fixed/improved g-buffer normals.

## Usage

- Install ReShade 6.8.0 or newer with full add-on support.
- Copy **TheElderScrollsVSkyrimGraphicalUpgrade.addon64**, **nvngx_dlss.dll** and **GraphicalUpgrade** folder into the game folder where **SkyrimSE.exe** is (ReShade should be installed in the same folder).

## Notes

- "Snow Shader" (bEnableImprovedSnow) needs to be disabled.

## Compilation

- You can clone [ReShade](https://github.com/crosire/reshade) and add TheElderScrollsVSkyrimGraphicalUpgrade project to Examples solution, then build the project.
