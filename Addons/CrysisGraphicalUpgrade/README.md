# CrysisGraphicalUpgrade

- Modern borderless window (flip mod, tearing).
- SMAA anti aliasing.
- 16x anisotropic filtering.
- Accurate FPS limiter.
- Upgraded render targets.
- Greatly reduced input lag.

## Usage

- Install ReShade 6.8.0 or newer with full add-on support.
- Copy **CrysisGraphicalUpgrade.addon32** (for 32 bit game EXE) or **CrysisGraphicalUpgrade.addon64** (for 64 bit game EXE), and **GraphicalUpgrade** folder in the game folder where **Crysis.exe** is (ReShade should be installed in the same folder).

## Notes

- It works (should be used) with DirectX 10 only.
- On lower graphical settings game may visualy break. Recommended "VERY HIGH".

## Compilation

- You can clone [ReShade](https://github.com/crosire/reshade) and add CrysisGraphicalUpgrade project to Examples solution, then build the project.
